The Challenge

We are only given this simple code :

from Crypto.PublicKey import RSA
from Crypto.Util.number import long_to_bytes
import os

def encrypt(key, pl):
    return pow(pl, key.e, key.n)

def decrypt(key, ct):
    return pow(ct, key.d, key.n)

if __name__ == "__main__":
    key = RSA.generate(2048)

    flag = os.getenv("FLAG", "404CTF{Fake_Flag}").encode()

    print("[INFO] Bienvenue dans le système interne de récupération des données. Voici les paramètres publiques :")

    print(str({
        "n": key.n,
        "e": key.e,
        "encrypted_flag": encrypt(key, int(flag.hex(), 16))
    }))

    print("[SAISIE] Veuillez entrer un message à déchiffrer :")

    try:
        userinput = int(input("> "))
    except ValueError:
        print("[ERREUR] Entrée invalide. Veuillez entrer un entier.")
        exit(1)

    result = decrypt(key, userinput)

    if flag in long_to_bytes(result):
        print("[ALERTE] Tentative d'accès à des données sensibles détectée.")
    else:
        print("[SUCCÈS] Voici le résulat du calcul :")
        print(str(result))

This is a classic chosen cyphertext attack on RSA (with no padding) with a decypher oracle.

The problem

We are given the cyphertext of the flag and we can decypher any decypher we want. Seems easy right ?

But the twist is we can’t directly decrypt the flag cyphertext because if the decrypted plaintext contains the flag the programm reject our input. Sow we just need to modify a little bit the encrypted flag in a way that when decrypted it does not contain teh flag but we can still deduce what it was.

RSA homomorphism

The key of this challenge is to use RSA homomorphism property which is :

enc(a) * enc(b) = enc(a * b)

This way if a is our encrypted_flag : a = encrypted_flag = enc(flag) and b is a known value that we choose. Since we know the public key parameters : key.n and key.e, we can encrypt b to get enc(b) and send : enc(b) * encrypted_flag .

The oracle will give us : result dec(enc(flag) * enc(b)) = dec(enc(flag * b)) = flag b

This surely does not contain flag so it passes the security check. But we can still recover it by dividing result by our known b !

Here’s the final solve script :

from pwn import *
from Crypto.Util.number import long_to_bytes
import json

def encrypt(e, n, pl):
    return pow(pl, e, n)

HOST = "challenge.404ctf.fr"
PORT = 10005


r = remote(HOST, PORT)

r.recvuntil(b"publiques :\n")
params = json.loads(r.recvline().strip().replace(b"'", b"\"").decode())

known = 2

userinput = encrypt(int(params["e"]), int(params["n"]), known) * int(params["encrypted_flag"])
r.sendlineafter(b"> ", str(userinput).encode())

r.recvuntil(b"du calcul :\n")

result = int(r.recvline().strip())

flag = result // known
flag = long_to_bytes(flag)
log.info(f"FLAG : {flag.decode()}")

r.close()
